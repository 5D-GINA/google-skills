# AI Morning Report Skill（AI 晨報技能）

Status: `DRAFT`

## Purpose（目的）

建立每日固定格式的 AI 晨報，支援 Gina 快速掌握 AI 圈最新消息、安全事件、TED / 論文觀點與 AI 英文學習。

## Daily Modules（每日四模組）

### 1. AI International News（AI 國際新聞）

- 每日 3 則
- 優先最新、重要、可落地
- 必須附來源
- 標示 Verified / Inference / Unknown

### 2. AI Security Brief（AI 安全快報）

- 最新漏洞
- Prompt Injection（提示注入）
- Agent 風險
- 開源工具安全
- 對五次元母體的影響

### 3. TED / Paper / Viewpoint（TED / 論文 / 觀點）

- 每日 1 則
- 必須提煉可收錄到 AI 共智課程的內容

### 4. AI English x 5（AI 英文五單字）

每個單字固定格式：

```text
Word（單字）:
Pronunciation（發音）:
KK（音標）:
Part of Speech（詞性）:
Chinese（中文）:
Example Sentence（例句）:
Sentence Pronunciation（例句發音）:
Sentence KK（例句音標）:
Translation（中文翻譯）:
```

## Weekly Review（每週複習）

每週日新增：

- 本週 10–15 個核心單字
- 本週重要例句
- 中翻英 / 英翻中 / 填空小測驗
- 100–150 字 AI 小短文
- 全文發音與音標
- 中文翻譯

## Evidence Rule（證據規則）

新聞、安全、TED、論文不可無來源摘要。

若資料來源不足，必須標示：

```text
Unknown（未確認資訊）
```

## Lessons Learned（實戰教訓）

AI 晨報不只是資訊整理，也是長期英文、治理與課程素材複利系統。每日輸出要能回流到 Obsidian（知識庫）與 AI 共智課程資料庫。
